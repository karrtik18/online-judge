# Online Judge Application

A full-stack Online Judge system supporting problem browsing, code submission, automated execution via an online compiler service, leaderboard tracking, and AI-assisted problem help.

## 🚀 Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Axios
- **Backend**: Node.js, Express, MongoDB, Mongoose, JWT, Nodemailer, Gemini API
- **Online Compiler**: Node.js, Execution Engine
- **Deployment**: Docker, AWS ECR

---

## 🛠️ Setup & Installation

### Prerequisites
- Node.js 18+
- MongoDB instance

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/karrtik18/online-judge.git
cd online-judge
```

### 2️⃣ Backend Setup
```bash
cd backend
npm install
npm run dev
```

### 3️⃣ Frontend Setup
```bash
cd ../frontend
npm install
npm run dev
```

### 4️⃣ Online Compiler Setup
```bash
cd ../online-compiler
npm install
npm start
```
